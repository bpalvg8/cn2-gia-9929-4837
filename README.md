## 回程比去程重要，下单前花五分钟验证

大部分测评只报一个 ping 值，这个数字参考价值有限。真正决定你晚上看视频卡不卡、SSH 会不会掉线的，是**回程路由**，也就是数据从机房回国内走的那条路径。去程走优化线路、回程绕回公共互联网的机器很常见，只看去程延迟会误判。

验证方法不复杂。AkkoCloud 三个地区都提供公开的 Looking Glass 页面，从官网导航可以进入。操作步骤：

1. 用 Looking Glass 做 traceroute，目标填你自己家的公网 IP，看回程经过哪些节点。走 CN2 的路径会出现 `59.43.x.x` 这类地址段，绕路的路径会看到一堆国际 transit 节点。
2. 直接 ping 测试 IP（圣何塞是 45.9.10.146），看延迟和丢包。工作日晚上 8 点到 11 点测一次，凌晨再测一次，两组数据对比才有意义。
3. 关注的是延迟的**波动幅度**，不是绝对值。白天 150ms、晚上 300ms 的机器，体验比稳定 180ms 的差得多。

这一步花五分钟，能避免年付之后发现晚高峰照样卡。商家提供 Looking Glass 本身就是个正面信号，说明它不怕你验。
